01 / PRINCIPLES

Less noise. More signal.

The visual hierarchy is built for long sessions, dense information, and quick decisions.

Calm density

Keep related information close, with enough breathing room to make it easy to scan.

Meaningful color

Use neutral surfaces for structure and blue for focus, highlights, and primary buttons; use green and violet for labeled states.

Context stays visible

Preserve navigation, file identity, and action state without competing with the main task.

Code & technical text

Cascadia Mono is the dedicated face for code blocks, diffs, file previews and terminal text. It is installed on the reference Windows machine; other devices use Consolas, SF Mono, Liberation Mono or a system monospace fallback. The font is not bundled, so availability can vary.

07 / CONTENT

Preview the content, keep the context.

The preview shell provides orientation while the file’s renderer handles its own content.

Markdown & source

Offer a clear filename and a switch between formatted content and source. Code fences keep their language label and monospace styling.

HTML

Rendered pages use an isolated iframe in the inspected build. Their own CSS controls the page; app chrome remains outside it.

Tables & documents

Use specialized viewers for tables, PDF, notebooks, and office formats. Surface loading, errors, and truncation where relevant.

Media & large files

Choose a renderer suited to the content and keep navigation and file identity visible. Avoid presenting a preview as a full editor.

08 / GUARDRAILS

Make the signal readable.

Validate every color combination in its rendered context, including hover and focus states.

Contrast matters. Target 4.5:1 for normal text and 3:1 for large text and essential non-text indicators. T3’s subtle default borders and input boundaries are below 3:1 against their canvas; provide another visible boundary when needed. Some original dark syntax colors also fall short. The dark primary button uses white on #346bf1 at 4.65:1, with little margin above the 4.5:1 normal-text target. Check focus rings after opacity and compositing.
Keyboard & focus

Use semantic controls, accessible labels, and an unmistakable focus indicator. Test the full flow without a mouse.

Motion & size

Respect reduced motion, support resizing, and aim for 44px targets where practical. Do not rely on color alone for state.
